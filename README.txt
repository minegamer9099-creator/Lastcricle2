LAST CIRCLE - Android project (WebView wrapper, fully offline)

Option A - Android Studio (PC): File > Open this folder, then Build > Build APK(s).
Option B - phone only: create a free GitHub repo, upload this folder contents
  (keep the .github folder), open Actions > Build APK > Run workflow, download the
  "LastCircle-apk" artifact (unzip it, install the .apk).
APK is signed with the debug key so it installs directly (allow "install unknown apps").
Game file: app/src/main/assets/index.html
